# Financial Cycles

Ένας offline προσωπικός οικονομικός tracker βασισμένος σε **κύκλους**: ανεξάρτητοι στόχοι εσόδων ή όρια εξόδων για μια συγκεκριμένη περίοδο, με δικό τους ιστορικό συναλλαγών και ένα ρητό «κλείσιμο» που είναι το μόνο πράγμα που μετακινεί το Balance.

Ολόκληρη η εφαρμογή είναι ένα αρχείο: `index.html`. Χωρίς build, χωρίς npm, χωρίς server, χωρίς CDN, χωρίς frameworks.

---

## Άνοιγμα

Κάνε **διπλό κλικ στο `index.html`**. Ανοίγει σε οποιονδήποτε σύγχρονο browser (Chrome, Edge, Firefox, Safari) απευθείας από το `file://`. Δεν χρειάζεται σύνδεση στο internet — ούτε την πρώτη φορά.

Τα δεδομένα αποθηκεύονται τοπικά στο `localStorage` του browser, με κλειδί `financial-cycles.state.v1`.

---

## Βασικές έννοιες

**Κύκλος.** Έχει τύπο (`Έσοδο` ή `Έξοδο`), ποσό-στόχο, περίοδο (εβδομαδιαία / μηνιαία / προσαρμοσμένη) και λίστα συναλλαγών. Όλα τα ποσά συναλλαγών εισάγονται ως **θετικοί** αριθμοί· ο τύπος του κύκλου καθορίζει τη σημασία τους.

**Συναλλαγές δεν αλλάζουν ποτέ το Balance.** Ενημερώνουν μόνο το «πραγματικό ποσό» του κύκλου και τον δακτύλιο προόδου.

**Το Balance αλλάζει μόνο σε τρεις περιπτώσεις:**

1. κλείσιμο κύκλου (settlement),
2. επαναφορά κλεισίματος (reversal),
3. χειροκίνητη προσαρμογή.

**Το Balance δεν αποθηκεύεται ποτέ ως μεταβλητός αριθμός.** Υπολογίζεται πάντα:

```
Balance = αρχικό Balance + άθροισμα όλων των εγγραφών του ιστορικού
```

**Μαθηματικά κλεισίματος** (χωρίς καμία απόκλιση):

```js
income  →  adjustment = πραγματικό − στόχος
expense →  adjustment = στόχος − πραγματικό
```

Ένα έσοδο που ξεπέρασε τον στόχο αυξάνει το Balance· ένα έξοδο που έμεινε κάτω από το όριο επίσης.

**Το κλείσιμο είναι idempotent** με δύο ανεξάρτητες δικλείδες: ένας κλειστός κύκλος δεν ξανακλείνει, και ένα `settlementId` που υπάρχει ήδη στο ιστορικό δεν εφαρμόζεται δεύτερη φορά. Διπλά κλικ, διπλή υποβολή ή reload δεν μπορούν να διπλογράψουν ένα κλείσιμο.

**Καμία εγγραφή ιστορικού δεν διαγράφεται ποτέ.** Η επαναφορά προσθέτει εγγραφή αντιλογισμού· και οι δύο μένουν ορατές στο ιστορικό.

## Δείκτης προόδου

| Κατάσταση | Δακτύλιος | Κείμενο |
|---|---|---|
| 0–100% | πράσινο γέμισμα, γκρι υπόλοιπο | `Εντός στόχου` |
| >100% και η υπέρβαση είναι αρνητική | εντελώς κόκκινος, πραγματικό ποσοστό (π.χ. 125%) | `Υπέρβαση: 125 €` |
| >100% και η υπέρβαση είναι θετική | παραμένει πράσινος + χρυσό σήμα | `Πλεόνασμα: +200 €` |

Το χρώμα δεν στέκει ποτέ μόνο του: κάθε κατάσταση συνοδεύεται από ορατό κείμενο (`Εντός στόχου`, `Υπέρβαση`, `Έλλειμμα`, `Πλεόνασμα`, `Ανοιχτός`, `Κλειστός`, `Εκπρόθεσμος`) και κάθε δακτύλιος έχει πλήρη εναλλακτική περιγραφή για screen readers.

## Ποσά

Όλα τα ποσά είναι **ακέραια λεπτά**. Δεν χρησιμοποιείται ποτέ αριθμητική κινητής υποδιαστολής για χρήμα (`10,10 + 20,20` δίνει ακριβώς `3030` λεπτά, όχι `3029.9999999999995`).

Ο parser δέχεται:

| Είσοδος | Αποτέλεσμα (λεπτά) |
|---|---|
| `10,50` | `1050` |
| `10.50` | `1050` |
| `1.000,50` | `100050` |
| `1000,50` | `100050` |
| `1,234,567.89` | `123456789` |
| `€ 1.234,56` | `123456` |
| `-25` | `-2500` |

Και **απορρίπτει** αντί να μαντεύει: `abc`, `1.2.3`, κενό, `Infinity`, `NaN`, `10,555` (πάνω από 2 δεκαδικά), καθώς και τα **διφορούμενα** `1,000` και `1.000` — ένας μόνο διαχωριστής με ακριβώς τρία ψηφία μετά δεν μπορεί να διακριθεί από χιλιάδες. Το μήνυμα λάθους προτείνει τη σαφή μορφή (`1.000,50`, `1000,50` ή `1000`).

## Backup

**Εξαγωγή:** `Δεδομένα και Backup → Εξαγωγή backup (JSON)`. Το αρχείο έχει τη μορφή:

```json
{ "schemaVersion": 1, "exportedAt": "...", "applicationName": "Financial Cycles", "applicationState": { ... } }
```

**Εισαγωγή:** `Εισαγωγή backup` → προεπισκόπηση (πλήθος κύκλων, συναλλαγών, εγγραφών ιστορικού, έκδοση σχήματος, ημερομηνία εξαγωγής, πρόβλεψη συγχώνευσης) → δύο τρόποι:

- **Αντικατάσταση όλων** — τα τρέχοντα δεδομένα αντικαθίστανται (με επιβεβαίωση).
- **Συγχώνευση** — προστίθεται μόνο ό,τι έχει άγνωστο ID (κύκλοι, συναλλαγές, settlements, εγγραφές ιστορικού). Η εισαγωγή του ίδιου backup δύο φορές δεν διπλογράφει τίποτα.

**CSV:** ξεχωριστές εξαγωγές για συναλλαγές και για το ιστορικό Balance. UTF-8 **με BOM** (ανοίγουν σωστά στο Excel με ελληνικά), διαχωριστής `;`, ελληνικές επικεφαλίδες, σωστό escaping κομμάτων, ερωτηματικών και εισαγωγικών.

**Συμβουλή:** τα δεδομένα ζουν στο `localStorage` ενός συγκεκριμένου browser και προφίλ. Καθαρισμός δεδομένων περιήγησης, αλλαγή browser ή χρήση ανώνυμης περιήγησης σημαίνει απώλεια. **Κάνε τακτική εξαγωγή backup.**

**Πλήρης διαγραφή:** απαιτεί να πληκτρολογήσεις ακριβώς `ΔΙΑΓΡΑΦΗ`.

## Δεδομένα επίδειξης

Το κουμπί `Φόρτωση δεδομένων επίδειξης` εμφανίζεται **μόνο όταν δεν υπάρχουν δικά σου δεδομένα** και δεν φορτώνεται ποτέ αυτόματα. Περιλαμβάνει έναν κύκλο εσόδων κάτω από τον στόχο, έναν πάνω, έναν κύκλο εξόδων κάτω από το όριο και έναν πάνω.

Όσο η καρτέλα παραμένει ανοιχτή, εμφανίζεται κουμπί `Αφαίρεση δεδομένων επίδειξης` που επαναφέρει την προηγούμενη κατάσταση με ένα κλικ. Αν κάνεις reload πρώτα, η αφαίρεση γίνεται με την πλήρη διαγραφή δεδομένων.

## Έλεγχος ορθότητας

```bash
node dev/verify.mjs
```

Το `dev/verify.mjs` εντοπίζει την περιοχή `CORE` μέσα στο `index.html` (ανάμεσα στους δείκτες `/* ==== CORE START ==== */` και `/* ==== CORE END ==== */`), την εκτελεί σε `node:vm` και τρέχει 127 ελέγχους: μαθηματικά κλεισίματος, idempotency, κύκλο close → reopen → edit → close, ακρίβεια λεπτών, parser ποσών, επαναληπτικότητα ημερομηνιών με δίσεκτα έτη, και idempotency της συγχώνευσης.

Είναι εργαλείο ανάπτυξης — η εφαρμογή δεν το φορτώνει και δεν εξαρτάται από αυτό. Έξοδος `0` όταν όλοι οι έλεγχοι περνούν.

## Προσβασιμότητα

- Κάθε πεδίο έχει ορατή ετικέτα· κάθε κουμπί έχει προσβάσιμο όνομα.
- `Escape` κλείνει τα modals· η εστίαση παγιδεύεται μέσα τους και επιστρέφει στο κουμπί που τα άνοιξε.
- Ορατά focus rings, σημασιολογικό HTML, ARIA μόνο όπου χρειάζεται.
- Περιοχές `aria-live` για toasts και μηνύματα ελέγχου.
- Οι κινήσεις σέβονται το `prefers-reduced-motion`.
- Σκοτεινό θέμα από προεπιλογή, με εναλλακτικό φωτεινό.

## Γνωστοί περιορισμοί

1. **Μόνο τοπική αποθήκευση.** Δεν υπάρχει λογαριασμός, συγχρονισμός, cloud ή σύνδεση με τράπεζα — εξ ορισμού. Τα δεδομένα δεν φεύγουν ποτέ από τη συσκευή. Η μεταφορά σε άλλη συσκευή ή browser γίνεται μόνο με εξαγωγή/εισαγωγή backup.

2. **Ένα προφίλ ανά browser.** Δεν υπάρχει διαχωρισμός χρηστών· όποιος ανοίγει το αρχείο στο ίδιο προφίλ βλέπει τα ίδια δεδομένα. Δεν υπάρχει κρυπτογράφηση — τα δεδομένα είναι απλό JSON στο `localStorage`.

3. **Το `localStorage` δεν είναι πάντα διαθέσιμο.** Σε ανώνυμη περιήγηση ή με αυστηρές ρυθμίσεις απορρήτου, η ανάγνωση/εγγραφή μπορεί να αποτύχει. Η εφαρμογή δεν καταρρέει: εμφανίζει ελληνικό μήνυμα, κρατά ανέπαφο το αρχικό περιεχόμενο, **παγώνει τις εγγραφές** ώστε να μη χαθεί τίποτα, και προσφέρει «εξαγωγή ακατέργαστων δεδομένων» πριν από οποιαδήποτε επαναφορά (που απαιτεί ρητή επιβεβαίωση με πληκτρολόγηση `ΔΙΑΓΡΑΦΗ`).

4. **Διφορούμενα ποσά απορρίπτονται.** Τα `1,000` και `1.000` δεν γίνονται δεκτά. Αυτό είναι σκόπιμο: το να μαντέψει ο parser 1000 € ή 1,00 € θα ήταν χειρότερο από ένα σαφές μήνυμα λάθους.

5. **Δεν υπάρχει undo γενικού σκοπού.** Αναιρείται μόνο το κλείσιμο κύκλου (μέσω επαναφοράς). Η διαγραφή συναλλαγής ή κύκλου είναι οριστική — γι' αυτό ζητείται πάντα επιβεβαίωση.

6. **Η διαγραφή κλειστού κύκλου δεν αγγίζει το ιστορικό.** Οι εγγραφές του settlement/reversal παραμένουν (καμία εγγραφή δεν διαγράφεται ποτέ), άρα το Balance δεν αλλάζει. Το ιστορικό δείχνει τότε εγγραφές που παραπέμπουν σε κύκλο που δεν υπάρχει πλέον.

7. **Η συγχώνευση κρατά το δικό σου αρχικό Balance.** Το `initialBalanceCents` του αρχείου αγνοείται κατά τη συγχώνευση (χρησιμοποιείται μόνο στην αντικατάσταση), ώστε να μη μετακινείται σιωπηλά το Balance σου.

8. **Οι κύκλοι δεν κλείνουν ποτέ αυτόματα.** Ένας κύκλος με ημερομηνία λήξης στο παρελθόν παίρνει σήμα `Εκπρόθεσμος` και περιμένει εσένα.

9. **Οι επαναλαμβανόμενοι κύκλοι δεν δημιουργούνται αυτόματα.** Η επόμενη περίοδος προτείνεται μόνο τη στιγμή του κλεισίματος. Οι μηνιαίοι κύκλοι χρησιμοποιούν clamping ημέρας: 31 Ιανουαρίου → 28 (ή 29) Φεβρουαρίου, ποτέ 3 Μαρτίου.

10. **Η μορφοποίηση νομίσματος εξαρτάται από τον browser.** Χρησιμοποιείται `Intl.NumberFormat('el-GR', { style:'currency', currency:'EUR' })`, με απλό fallback (`1.234,56 €`) αν το `Intl` λείπει. Το νόμισμα είναι σταθερά EUR.

11. **Τα CSV χρησιμοποιούν `;` ως διαχωριστή** (και ελληνικά δεκαδικά με κόμμα), που ταιριάζει με ελληνικές ρυθμίσεις Excel. Σε εργαλείο που περιμένει κόμμα ως διαχωριστή, δήλωσε ρητά το `;`.
